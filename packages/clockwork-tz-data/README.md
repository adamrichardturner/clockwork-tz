# clockwork-tz-data

Compiled [IANA tzdb](https://www.iana.org/time-zones) releases for the
[`clockwork-tz`](https://www.npmjs.com/package/clockwork-tz) `embedded-tzdb` engine.

- `tzdb.json`: the compiled database (zones, links, list of user-facing zones)
- `manifest.json`: version, SHA-256 of `tzdb.json`, and an Ed25519 signature over
  `${version}\n${sha256}`

Versions are `1.<year>.<release>`, so tzdb `2026f` is `1.2026.6`.
clockwork-tz fetches `https://cdn.jsdelivr.net/npm/clockwork-tz-data@1/manifest.json`
and only loads data whose signature verifies against the public key built into
the library.

This package is generated by `scripts/build-tzdb.ts` and `scripts/sign-tzdb.ts`
in the clockwork-tz repository. Do not edit it by hand.
